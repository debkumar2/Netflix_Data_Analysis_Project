# 🎬 Netflix Movies & TV Shows Data Analysis

## 📌 Project Overview

This project focuses on analyzing Netflix Movies and TV Shows using Python.

The objective is to explore Netflix's content library, identify patterns and trends, understand content distribution, and perform statistical analysis to extract meaningful information from the dataset.

This project demonstrates practical skills in Python, data cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization.

## 🎯 Project Objectives

- Understand the Netflix dataset structure.
- Clean and preprocess raw data.
- Analyze Movies vs TV Shows distribution.
- Identify content trends over time.
- Explore country-wise content distribution.
- Analyze popular genres and content ratings.
- Understand Netflix movie duration patterns.
- Perform statistical analysis on relevant variables.
- Visualize important findings using Python.

## 📂 Dataset Information

**Dataset Name:** Netflix Movies and TV Shows

**Dataset Source:** [Netflix Movies and TV Shows – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

**File Name:** `netflix_titles.csv`

The dataset contains information about Netflix titles, including:

- show_id
- type
- title
- director
- cast
- country
- date_added
- release_year
- rating
- duration
- listed_in
- description

**Original Dataset Size:** 8,807 rows and 12 columns.
